Homework 5 — Bigfoot sightings visualizations

This page supports IS 445 (Spring 2026): two Altair / Vega-Lite views of the same BFRO Bigfoot report dataset, with one interactive control beyond default pan and zoom.

The Data The Analysis

Plot 1 — Sightings by year and classification

This chart shows how many BFRO reports fall in each year from 1950 through 2022, broken down by classification (Class A, B, or C). Years are on the horizontal axis as an ordinal field; the vertical axis is a quantitative count of rows (aggregated automatically). Color encodes classification nominally using the tableau10 palette so the three classes stay visually distinct without implying order. On the analysis side, rows without latitude, longitude, date, classification, or state were dropped; date was parsed with pd.to_datetime, invalid dates removed, and year extracted; the series was restricted to 1950–2022 and to points inside continental US lat/lon bounds so the map and time series stay comparable.

Plot 2 — Geographic map with state emphasis

The second view plots each report in a projected US map: longitude and latitude are quantitative positions on an albersUsa projection; color again shows classification, here with the dark2 nominal scheme for strong separation on the basemap. Tooltips show state, classification, year, and county. The same cleaned dataframe as Plot 1 is used, so only geocoded continental US reports in the chosen year window appear.

Interactivity

The map is linked to a dropdown bound selection on state. Choosing a state increases the circle size for points in that state and shrinks all others, which makes a dense national scatter easier to read when you want to focus on one state’s pattern. This goes beyond the default .interactive() pan/zoom behavior because it filters emphasis through an explicit parameter and conditional encoding rather than only changing the view transform.
